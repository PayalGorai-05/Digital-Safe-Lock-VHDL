# Digital Safe Lock using VHDL

## Overview
A digital safe lock system developed using VHDL that verifies a 4-bit password and generates unlock or alarm signals based on authentication results.

## Features
- Password verification
- Unlock signal generation
- Alarm generation for incorrect password
- Behavioral simulation in Vivado

## Tools Used
- VHDL
- Vivado

## Project Structure

Digital-Safe-Lock-VHDL
├── src
├── tb
└── simulation

## Simulation Result
The design successfully verifies correct and incorrect passwords and generates appropriate outputs.
